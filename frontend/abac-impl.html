Attribute-Based Access Control (ABAC) in Keycloak

Learn how to build fine-grained, dynamic, and context-aware security policies using user, resource, and environment attributes in Keycloak.

3. Implementing ABAC

To implement Attribute-Based Access Control (ABAC) in Keycloak, attributes must be populated across three logical layers:

  1. Subject (User) Attributes: Defined in Keycloak on User profiles (e.g., department, clearance_level).
  2. Resource Attributes: Defined inside the Keycloak Authorization tab under Resources (e.g., department, classification_level).
  3. Context/Environment Attributes: Provided at runtime within the evaluation request context (e.g., network_location).
💡 Modern Keycloak Rule: To write dynamic attribute matching rules, Keycloak uses JavaScript Policies. In Keycloak 18 and newer (including Keycloak 26), uploading raw JavaScript scripts directly via the Admin Console UI is disabled for security reasons. Instead, policies must be packaged into a custom provider JAR file and deployed to the server's filesystem.

📦 Understanding JARs in the Keycloak World

If you're new to the Java ecosystem, a JAR (Java Archive) is essentially a standard ZIP file. It bundles Java classes, static assets, scripts, and metadata files together into a single file so they can be easily distributed and loaded by a Java runtime.

Keycloak uses JAR files to enable its core customization system:

  • Service Provider Interface (SPI): Keycloak is designed to be fully modular. Almost every feature (custom login screens, SMS authenticators, user databases, and policy checkers) is defined by an SPI. Developers create custom plugins (called providers) by implementing these SPIs and bundling their files into a JAR.
  • The Script Provider SPI: The Keycloak JavaScript engine operates as an SPI. When you package your .js files inside a provider JAR and place it in Keycloak's /opt/keycloak/providers/ directory, the server extracts and registers those scripts at startup, making them available as selectable policies in the Admin UI.

Anatomy of a JavaScript Policy JAR

To make Keycloak recognize the scripts inside your JAR, you must package them using a specific directory structure. A descriptor file named keycloak-scripts.json must reside inside the META-INF/ directory:

JAR Directory Structure 
abac-policy-provider.jar
├── abac-policy.js                  # The script containing our ABAC logic
└── META-INF/
    └── keycloak-scripts.json       # Descriptor metadata registering the script

1️⃣ The Deployment Descriptor: keycloak-scripts.json

This JSON file registers the JS files inside the JAR as custom policies. When Keycloak deploys this JAR, it reads this descriptor and creates a policy entry in the Admin Console database matching these details.

lab-code/META-INF/keycloak-scripts.json 
{
    "policies": [
        {
            "name": "Verify Dept and Clearance ABAC Policy",
            "fileName": "abac-policy.js",
            "description": "Verify Dept and Clearance ABAC Policy"
        }
    ]
}

⚠️ Key Java Integration Concept: Since the policy engine runs on Java, values fetched from resource.getAttributes() return Java collections (like java.util.List). We implement the helper getSingleValue() to safely extract values from these Java objects and map them to standard JavaScript scalar types.
lab-code/abac-policy.js 
/**
 * Keycloak JavaScript Authorization Policy for Attribute-Based Access Control (ABAC)
 * 
 * Rules:
 * 1. User's department MUST match the Resource's department.
 * 2. User's clearance level MUST be greater than or equal to the Resource's classification level.
 * 3. Level 3 (Confidential) resources can only be accessed from the "Office Network" (Environment constraint).
 */

// Helper to convert attribute values from Keycloak attribute entries or Java collections to simple JS strings.
function getSingleValue(attr) {
    if (!attr) return null;

    // Keycloak attribute entries may expose either asString() or asString(index).
    if (typeof attr.asString === 'function') {
        try {
            return attr.asString();
        } catch (e) {
            return attr.asString(0);
        }
    }

    // Resource attributes are commonly java.util.List values.
    if (typeof attr.get === 'function' && typeof attr.isEmpty === 'function') {
        return attr.isEmpty() ? null : attr.get(0);
    }

    // Fallback for JS arrays.
    if (Array.isArray(attr) && attr.length > 0) {
        return attr[0];
    }

    // Final fallback for plain scalar-like objects.
    return attr.toString();
}

function normalizeText(val) {
    if (val === null || val === undefined) return null;
    return val.toString().trim().toLowerCase();
}

function safeToString(value) {
    if (value === null || value === undefined) return "None";
    try {
        return value.toString();
    } catch (e) {
        return "[unprintable]";
    }
}

function listAttributeKeys(attrs) {
    if (!attrs) return "[none]";

    try {
        if (typeof attrs.keySet === 'function') {
            return attrs.keySet().toString();
        }
    } catch (e) {}

    try {
        if (typeof attrs.getAttributes === 'function') {
            return attrs.getAttributes().keySet().toString();
        }
    } catch (e) {}

    try {
        return Object.keys(attrs).join(', ');
    } catch (e) {
        return "[unknown]";
    }
}

// 1. Get the evaluation context and resource info
var context = $evaluation.getContext();
var identity = context.getIdentity();
var permission = $evaluation.getPermission();
var resource = permission.getResource();

// 2. Retrieve User (Subject) Attributes
var userAttributes = identity.getAttributes();
var userDept = getSingleValue(userAttributes.getValue('department'));
var userClearanceStr = getSingleValue(userAttributes.getValue('clearance_level')); // e.g., "1", "2", "3"

// 3. Retrieve Resource Attributes (resource.getAttributes() returns a Map<String, List<String>>)
var resourceAttributes = resource.getAttributes();
var resourceDept = getSingleValue(resourceAttributes.get('department'));
var resourceClassStr = getSingleValue(resourceAttributes.get('classification_level')); // e.g., "1", "2", "3"

// 4. Retrieve Environment Attributes
var contextAttributes = context.getAttributes();
var networkType = getSingleValue(contextAttributes.getValue('network_location'));

// Helper to parse string level as integer
function parseLevel(valStr, defaultVal) {
    if (!valStr) return defaultVal;
    return parseInt(valStr, 10) || defaultVal;
}

var uLevel = parseLevel(userClearanceStr, 0);
var rLevel = parseLevel(resourceClassStr, 1);
var normalizedUserDept = normalizeText(userDept);
var normalizedResourceDept = normalizeText(resourceDept);
var normalizedNetworkType = normalizeText(networkType);

// Debug logging (will show up in Keycloak server console logs)
print("Evaluating ABAC Policy for User: " + identity.getId());
print("User Attribute Keys: " + listAttributeKeys(userAttributes));
print("Context Attribute Keys: " + listAttributeKeys(contextAttributes));
print("User Dept: " + safeToString(userDept) + " (normalized: " + safeToString(normalizedUserDept) + "), Clearance: " + uLevel);
print("Resource Dept: " + safeToString(resourceDept) + " (normalized: " + safeToString(normalizedResourceDept) + "), Classification: " + rLevel);
print("Network Location Parameter: " + safeToString(networkType) + " (normalized: " + safeToString(normalizedNetworkType) + ")");

// 5. Evaluate Rules
var departmentMatches = false;
if (normalizedUserDept && normalizedResourceDept) {
    departmentMatches = (normalizedUserDept === normalizedResourceDept);
}

var clearanceIsSufficient = (uLevel >= rLevel);

var environmentConstraintMet = true;
// Rule: If resource is Level 3 (highly confidential), force office network
if (rLevel >= 3) {
    if (normalizedNetworkType !== "office") {
        environmentConstraintMet = false;
        print("Access denied: Level 3 resource requires Office Network, current network is: " + safeToString(networkType));
    }
}

// 6. Grant or Deny Access
if (departmentMatches && clearanceIsSufficient && environmentConstraintMet) {
    print("ABAC Evaluation: GRANT");
    $evaluation.grant();
} else {
    print("ABAC Evaluation: DENY");
}
